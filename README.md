# Student Performance Prediction

A command-line Fundamentals of AI and ML project using a Decision Tree Classifier.

## Setup

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

Linux/macOS:
```bash
source .venv/bin/activate
```

Install dependencies:
```bash
pip install -r requirements.txt
```

## Run

```bash
python student_performance.py --study-hours 6 --attendance 80
```

The program prints test accuracy, a classification report, and a Pass/Fail prediction.

## Files

- `student_performance.py`: application
- `requirements.txt`: dependencies
- `REPORT.md`: report draft

## Limitation

The dataset is synthetic and small, so results are educational only and must not be used for actual academic decisions.
